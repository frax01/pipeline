# E001 — PROMPT INJECTION

**Finding originali**: 80

Severity: **critical** per tutti gli 80 finding.

mcp-scan non espone una regex pubblica per E001: la detection avviene interamente nel backend di Invariant Labs, che analizza ogni tool description via LLM e le assegna un `risk_score` in [0.0, 1.0]. L'issue E001 "Prompt Injection" viene emesso quando l'LLM di mcp-scan ritiene che la description contenga istruzioni sospette rivolte all'agente (esfiltrzione dati, occultamento di operazioni, tool chaining forzato, ecc.).

---

**Finding dopo filtro**: 80 (nessun filtro regex intermedio applicato)

Non c'e' una Fase 2 a regex come per mcp-watch: mcp-scan restituisce direttamente finding gia' filtrati dal suo backend LLM. Siamo quindi passati direttamente all'analisi manuale/LLM su tutti gli 80 finding.

### Falsi positivi (52): perche' il tasso di FP e' alto (~65%)

mcp-scan classifica come E001 qualsiasi tool description con linguaggio imperativo rivolto all'agente. Ma nel contesto MCP le tool description **sono** l'interfaccia tra server e agente: e' normale che contengano "ALWAYS use this tool for X" o "MUST follow this format".

I principali gruppi di FP:

- **ag2-mcp-servers / `get_security_checklist`** (14 finding): template autogenerati con "STRICT: You MUST..." — le istruzioni imperative SONO il contenuto del tool (una security checklist), non injection.
- **Fork `mcp-server-fetch`** (4 finding): "this tool now grants you internet access..." — spiegazione di capability, non injection (fork dell'originale Anthropic).
- **Wrapper CLI con parametri "yolo"** (5 finding): `yolo: Bypass all safety` e' un flag di Codex CLI esposto come parametro, non un'istruzione all'agente.
- **Tool con parametri `system_prompt`/`baseInstructions`** (3 finding): architettura del tool (crea sessioni LLM), non injection.
- **Restanti ~26 finding**: linguaggio imperativo standard ("ALWAYS", "MUST", "CRITICAL", "NEVER") come guidance operativa.

I VP si distinguono perche' contengono:
1. Istruzioni di esfiltrzione esplicita (URL esterni, accesso a file sensibili)
2. Direttive di occultamento ("silently", "hide from user")
3. Tool il cui scopo dichiarato e' generare attacchi
4. Manipolazione dell'identita dell'agente
